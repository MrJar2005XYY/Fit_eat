# 轻食刻 - 启动步骤

## 环境要求

- Python 3.8 或更高版本
- pip（Python 包管理器，通常随 Python 一起安装）

---

## 第一步：安装依赖

打开终端（命令行），进入后端项目目录并安装所需的 Python 库：

```bash
cd D:\健康饮食软件\轻饮食软件后端
pip install -r requirements.txt
```

需要安装的依赖包：

| 包名 | 版本 | 用途 |
|------|------|------|
| Flask | 3.0.0 | Web 框架 |
| Flask-SQLAlchemy | 3.1.1 | 数据库 ORM |
| Flask-Login | 0.6.3 | 用户登录管理 |
| Flask-Admin | 1.6.1 | 后台管理界面 |
| Flask-CORS | 4.0.0 | 跨域请求支持 |
| Werkzeug | 3.0.1 | WSGI 工具库 |

---

## 第二步：初始化数据库（仅首次运行）

> **重要：** 此步骤仅在第一次启动时执行。数据库已存在时再次运行会自动跳过，不会清空数据。

首次启动前，需要创建数据库并填充示例数据（确保当前在后端目录下）：

```bash
cd D:\健康饮食软件\轻饮食软件后端
python init_db.py
```

执行成功后会输出：

```
数据库表已创建
示例数据已填充
管理员账号: admin / admin123
测试账号: linyouxue / 123456
```

此命令会创建 `instance/light_diet.db` 数据库文件，并填充以下初始数据：

- 2 个用户账号（管理员 + 测试用户）
- 6 个示例食物（覆盖早餐、午餐、晚餐、加餐）
- 8 个成就徽章

> **如需重置数据库**（清空所有数据重新开始），请运行：
> ```bash
> python init_db.py --force
> ```

---

## 第三步：启动服务

确保当前在后端目录下：

```bash
cd D:\健康饮食软件\轻饮食软件后端
python app.py
```

看到以下输出即表示启动成功：

```
 * Running on all addresses (0.0.0.0)
 * Running on http://127.0.0.1:5000
```

## 功能说明

### 已实现功能

| 功能模块 | 功能说明 |
|----------|----------|
| 用户系统 | 注册、登录、个人资料编辑、修改密码、头像更换 |
| 饮食记录 | 添加/删除饮食记录、查看今日餐单、宏量营养素追踪 |
| 营养分析 | 六维营养雷达图、周卡路里图表、饮水追踪 |
| 食物库 | 食物列表浏览、搜索、详情查看、食物收藏 |
| AI方案 | 基于身体数据的个性化饮食方案生成 |
| 成就系统 | 成就展示、自动解锁（基于记录数量、连续打卡等） |
| 社区互动 | 发帖、点赞、评论、关注用户 |
| 管理后台 | 数据表增删改查、搜索筛选、CSV导出 |

### 数据库表

系统包含以下数据表：

- `users` - 用户信息
- `foods` - 食物库
- `diet_records` - 饮食记录（含热量、蛋白质、碳水、脂肪、纤维）
- `water_records` - 饮水记录
- `community_posts` - 社区帖子
- `comments` - 评论
- `likes` - 点赞
- `follows` - 关注关系
- `favorites` - 食物收藏
- `achievements` - 成就定义
- `user_achievements` - 用户成就解锁记录
- `ai_body_data` - AI身体数据

## 管理员后台

访问 http://localhost:5000/admin 可直接操作数据库，支持以下数据表的增删改查：

- 用户（User）
- 食物（Food）
- 饮食记录（DietRecord）
- 饮水记录（WaterRecord）
- 社区帖子（CommunityPost）
- 评论（Comment）
- 点赞（Like）
- 关注（Follow）
- 食物收藏（Favorite）
- 成就（Achievement）
- 用户成就（UserAchievement）
- AI身体数据（AIBodyData）

后台支持搜索、筛选和 CSV 导出。

## 重新初始化数据库

如需清空所有数据并重新开始，进入后端目录后运行：

```bash
cd D:\健康饮食软件\轻饮食软件后端
python init_db.py --force
```

> **注意**：此操作会删除所有用户数据和记录，不可恢复。日常启动只需运行 `python app.py`，无需重新初始化。

## 常见问题

### 端口被占用

如果提示 5000 端口已被占用，可以修改 `app.py` 最后一行的端口号：

```python
app.run(debug=True, host='0.0.0.0', port=5001)  # 改为 5001
```

### 依赖安装失败

尝试使用国内镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 数据库文件位置

SQLite 数据库文件位于：

```
D:\健康饮食软件\轻饮食软件后端\instance\light_diet.db
```

删除该文件后重新运行 `init_db.py` 可重建数据库。

### 登录失败

如果登录时提示"账户ID或密码错误"，请确认：
1. 账户ID是否正确（区分大小写）
2. 密码是否正确
3. 是否已运行 `init_db.py` 初始化数据库
